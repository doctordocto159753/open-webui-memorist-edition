# Memorist OpenWebUI

Memorist یک موتور حافظه local-first برای Open WebUI است. Open WebUI مالک تجربه چت و انتخاب مدل اصلی می‌ماند؛ Memorist در کنار آن پیام‌ها را محلی ثبت می‌کند، حافظه شواهددار می‌سازد، بازیابی انجام می‌دهد و Memory Context Attachment را جدا از متن کاربر تزریق می‌کند.

## صفحه کنترل مدل‌ها

چهار نقش اصلی جدا هستند:

- مدل چت اصلی: در Open WebUI انتخاب می‌شود و Memorist فقط آن را مشاهده می‌کند.
- مدل Pre-flight: قبل از درخواست چت برای برنامه‌ریزی حافظه اجرا می‌شود، محدود است و fail-open می‌ماند.
- مدل استخراج حافظه: بعد از پاسخ، در job پس‌زمینه اجرا می‌شود و از مدل چت اصلی استفاده نمی‌کند.
- مدل Embedding: مستقل است، در Lite پیش‌فرض غیرفعال است و با تغییر default نیاز به re-index ایجاد می‌کند.

Providerهای راه‌دور ممکن است متن انتخاب‌شده، واحدهای جمله، خلاصه‌های حافظه یا متن embedding را دریافت کنند. قبل از default شدن چنین profileهایی باید acknowledgement حریم خصوصی ثبت شود. کلیدهای خام در SQLite یا PostgreSQL ذخیره نمی‌شوند؛ فقط نام متغیر محیطی ذخیره می‌شود.
